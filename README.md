# 🇮🇳 India AQI Tracker

A simple and responsive web application that allows users to check the Air Quality Index (AQI) of cities with health reccommendations in India.

## 📌 About the Project

The India AQI Tracker is a beginner-friendly web project built to understand the fundamentals of web development using HTML, CSS, and JavaScript.

The project provides an easy-to-use interface for viewing air quality information and understanding AQI levels.

## ✨ Features

- 🔍 Search for cities
- 🌫️ Display AQI information
- 🎨 Color-coded AQI levels
- 📱 Responsive design
- ⚡ Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
